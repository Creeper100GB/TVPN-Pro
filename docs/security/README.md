# Security-Berichte (qa-security)

Hier liegen Reviews und Testberichte der Rolle qa-security, benannt nach Phase:
`review-<phase>.md`, `leak-matrix-<phase>.md`.

Regeln:

- Keine Entwarnung ohne Test. Immer schreiben, was getestet wurde und was nicht.
- Keine echten IPs, MACs, URLs oder Dateinamen in Berichten. Hashes und Codes genügen.
- Funde mit Schweregrad, Reproduktion und betroffener Komponente.
