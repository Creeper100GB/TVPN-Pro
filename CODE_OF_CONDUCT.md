# Verhaltenskodex

Kurz und ohne Juristendeutsch.

- Sei respektvoll. Kritik an Code ist erwünscht, Angriffe auf Menschen nicht.
- Keine Belästigung, keine Diskriminierung, keine Drohungen.
- Keine Anleitungen oder Hilfe für Straftaten. Das Projekt baut ein Datenschutzwerkzeug, keinen Tatwerkzeugkasten.
- Keine Sicherheitsversprechen in Beiträgen („anonym", „nicht zurückverfolgbar").
- Melde Sicherheitslücken vertraulich (siehe `SECURITY.md`), nicht als öffentliches Issue.

Bei Verstößen entscheiden die Maintainer; sie können Beiträge schließen oder Personen ausschließen. Melde Vorfälle über die im GitHub-Profil hinterlegte Kontaktmöglichkeit.
